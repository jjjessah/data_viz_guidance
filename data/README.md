# Demo data

Files in this folder are public, illustrative datasets for documentation and reproducible examples.

| File | Description |
| --- | --- |
| `median_household_income_by_state.csv` | State-level median household income demo values for bar-chart recipes |

## Source expectations

- Prefer regenerating production examples from [data.census.gov](https://data.census.gov/) or the Census API.
- Record table ID, vintage, and geography in script comments and page notes.
- Never commit confidential or unpublished data.
